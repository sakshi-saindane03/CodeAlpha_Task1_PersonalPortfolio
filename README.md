# Personal Portfolio Website

## Overview

This is a responsive personal portfolio website developed using HTML, CSS, and JavaScript. The website showcases my profile, skills, projects, education, achievements, certifications, and contact information in a modern and user-friendly design.

## Features

* Responsive design for desktop, tablet, and mobile devices
* Interactive navigation menu
* Active navigation link highlighting while scrolling
* Smooth scrolling between sections
* Typing text animation on the home page
* Scroll reveal animations using Intersection Observer
* Education cards with left and right slide animations
* Back-to-top button
* Skills section with progress bars
* Projects showcase section
* Achievements and Certifications section
* Contact information with social links

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Font Awesome Icons
* Google Fonts
